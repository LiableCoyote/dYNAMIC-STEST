# Spanish Republic conversion — image assets

New images for the conversion go here, referenced from scenes as
`img/es/...` (e.g. `card-image: img/es/leaders/largo_caballero.jpg`).

Layout:
- `img/es/leaders/` — portraits of political figures (PSOE, PCE, CEDA, etc.)
- `img/es/parties/` — party logos / posters
- `img/es/events/` — event illustrations

Rules:
- Every file must have a credits line in `credits_images.txt` (conversion
  section) stating a redistributable license, source URL, and attribution.
  No provenance, no commit.
- Until real art exists, scenes may use the shared `img/placeholder.jpg`.
- The original Weimar-era images under `img/` are kept until the content
  areas (H/K) replace their references; do not delete them here.
